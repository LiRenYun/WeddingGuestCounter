3. RSVP 表單系統

兩步驟流程

步驟一：選擇親友方（男方/女方）

步驟二：填寫詳細資訊

表單欄位

欄位 類型 驗證規則
side radio 必選（男方/女方）
name text 必填
pax number 1-99，預設 1
diet radio/number 單人：葷/素；多人：葷素分開計數，總和需等於參與人數
childSeat number 0+，預設 0
message textarea 選填

防呆機制 (Defense System)

  • 人數聯動：參與人數 > 1 時自動切換到葷素分開計數模式
  • 即時驗證：葷食 + 素食人數必須等於參與總人數
  • 錯誤提示：驗證失敗時顯示紅色錯誤訊息
  • 送出阻擋：validateRsvpForm() 函式在送出前進行最終驗證

關鍵函式

// 更新葷素驗證狀態
function updateDietErrorState() {
  const total = parseInt(rsvpPax.value);
  if (total > 1) {
    const meat = parseInt(dietMeat.value) || 0;
    const veg = parseInt(dietVeg.value) || 0;
    if (meat + veg !== total) {
      dietError.classList.remove('hidden');
    } else {
      dietError.classList.add('hidden');
    }
  }
}

// 表單驗證
function validateRsvpForm() {
  const totalPax = parseInt(rsvpPax?.value) || 1;
  if (totalPax > 1) {
    const meat = parseInt(dietMeat?.value) || 0;
    const veg = parseInt(dietVeg?.value) || 0;
    if (meat + veg !== totalPax) {
      dietError.classList.remove('hidden');
      alert(translations[currentLang]?.diet_error);
      return false;
    }
  }
  return true;
}

5. 戀愛 PK 大作戰遊戲

遊戲概念

邱比特 vs 月老的 2D 拋物線對戰遊戲，類似「百戰天蟲」風格

遊戲模式

  • 雙人對戰：玩家輪流操作邱比特與月老
  • 單人 vs 電腦：玩家操作邱比特，AI 自動操作月老

核心類別：LovePKGame

class LovePKGame {
  constructor() {
    this.canvas = document.getElementById('game-canvas');
    this.ctx = this.canvas.getContext('2d');
    this.width = 800;
    this.height = 420;
    this.mode = '2p'; // '2p' | 'cpu'
    this.currentTurn = 'cupid'; // 'cupid' | 'yuelao'
    this.state = 'idle'; // 'idle'|'charging'|'flying'|'gameover'
    this.cupidHP = 5;
    this.yuelaoHP = 5;
    this.wind = 0; // 風向 -3.5 ~ +3.5
    this.power = 0; // 蓄力 0~100%
    // ...
  }
}

遊戲流程

  1. 開局設定：選擇模式、先攻方
  2. 回合開始：隨機產生風向，更新 HUD
  3. 蓄力發射：長按按鈕/Canvas/空白鍵蓄力，放開發射
  4. 拋物線計算：
    • 初速度 = 7.0 + (power/100) × 14.0
    • 受風力影響：vx += wind × 0.022
    • 受重力影響：vy += 0.36
  5. 碰撞判定：
    • 命中對手 → 扣 1 HP，切換回合
    • 撞到櫻花神木 → 阻擋，切換回合
    • 墜地或出界 → 未命中，切換回合
  6. 勝負判定：任一方 HP = 0 時顯示勝利彈窗

AI 演算法

// 月老向左射，風向調整策略
let idealPower = 51.0;
if (this.wind > 0) {
  // 逆風（向右吹）需加力
  idealPower += this.wind * 6.0;
} else {
  // 順風（向左吹）需省力
  idealPower += this.wind * 3.1;
}
// 加入隨機誤差 ±3%
const jitter = (Math.random() * 6) - 3;
const targetPower = Math.min(100, Math.max(20, idealPower + jitter));

像素藝術繪製

  • drawPixelCupid() - 純手繪 16-bit 邱比特角色
  • drawPixelYueLao() - 純手繪 16-bit 月老角色
  • drawPixelSakuraTree() - 唯美櫻花神木
  • drawProjectile() - 金箭/紅繩圈拋物線
  • drawPowerBar() - 8-bit 蓄力能量條

6. 點擊粒子動畫系統

功能

每次滑鼠點擊時，在游標位置爆炸噴出 60 個像素粒子（愛心、方塊、星星等），帶有物理拋射動畫

實作

document.addEventListener('click', (e) => {
  const particleCount = 60;
  for (let i = 0; i < particleCount; i++) {
    const p = document.createElement('div');
    p.className = 'pixel-confetti';
    const symbols = ['💖', '▪', '⭐', '✨', '🌸', '💎', '❤️', '🔥'];
    p.innerText = symbols[Math.floor(Math.random() * symbols.length)];

    // 隨機爆炸角度與力道
    const angle = Math.random() * Math.PI * 2;
    const velocity = 100 + Math.random() * 200;
    const dx = Math.cos(angle) * velocity;
    const dy = Math.sin(angle) * velocity - 50;

    // 定位在滑鼠位置
    p.style.left = `${e.clientX}px`;
    p.style.top = `${e.clientY}px`;

    // CSS 變數控制動畫
    p.style.setProperty('--dx', `${dx}px`);
    p.style.setProperty('--dy', `${dy}px`);

    document.body.appendChild(p);
    p.addEventListener('animationend', () => p.remove());
  }
});

後端路由邏輯（GAS 端）

Google Apps Script 需要根據 formType 欄位路由到不同的 Sheet：

function doPost(e) {
  const data = JSON.parse(e.postData.contents);
  const sheet = SpreadsheetApp.getActiveSpreadsheet();

  if (data.formType === 'rsvp') {
    const rsvpSheet = sheet.getSheetByName('RSVP');
    rsvpSheet.appendRow([
      new Date(),
      data.name,
      data.side,
      data.pax,
      data.diet,
      data.childSeat,
      data.message
    ]);
  } else if (data.formType === 'wish') {
    const wishSheet = sheet.getSheetByName('Wishes');
    wishSheet.appendRow([
      new Date(),
      data.name,
      data.message
    ]);
  }

  return ContentService.createTextOutput('Success');
}

🌐 多語系實作詳解

翻譯鍵值管理

所有翻譯集中在 translations 物件，key 採用 snake_case 命名

命名規範

  • title_* - 頁面標題
  • btn_* - 按鈕文字
  • label_* - 表單標籤
  • placeholder_* - 輸入框提示
  • info_* - 資訊文字
  • game_* - 遊戲相關

新增翻譯的步驟

  1. 在 translations.zh 和 translations.ja 中加入同樣的 key
  2. 在 HTML 元素上加上 data-i18n="key"
  3. 呼叫 updateLanguage() 會自動更新所有標記元素

動態語系更新

部分內容是由 JavaScript 動態生成的，需要在語系切換時手動更新：

// 遊戲內的語系更新
if (window.lovePKGame) {
  window.lovePKGame.updateLanguageTexts();
}

// LovePKGame 類別內的方法
updateLanguageTexts() {
  this.updateHUD();      // 更新回合提示
  this.updateHpDisplay(); // 更新 HP 顯示
}

語系初始化流程

  1. 從 localStorage 讀取 wedding_lang
  2. 若不存在，預設為 'zh'
  3. DOMContentLoaded 時呼叫 updateLanguage()
  4. 使用者點擊切換按鈕時更新 currentLang 並重新呼叫

📝 技術債務與未來改進

已知限制

  • no-cors 模式：無法讀取 API 回應，無法判斷送出是否真正成功
  • 婚紗照片陣列為空：目前相簿功能未啟用
  • 無後退瀏覽器歷史：視圖切換未使用 History API
  • 無狀態持久化：重新整理會回到首頁

潛在改進方向

  • 使用 Google Sheets API（需 OAuth）以獲得更好的錯誤處理
  • 加入表單重複提交檢查（比對姓名+手機）
  • 實作賓客名單查詢功能
  • 新增 QR Code 打卡功能
  • 遊戲分數排行榜
  • SEO 優化（Meta tags、Open Graph）
